# Conexões Bíblicas Logos

Aplicativo de pesquisa bíblica de Gênesis a Apocalipse.

## Objetivo
Organizar conexões entre passagens bíblicas com rigor histórico-gramatical, referências verificáveis e distinção entre citação direta, alusão, paralelismo, cumprimento profético, tipologia e relação temática.

## Módulos planejados
- Painel inicial e pesquisa bíblica
- Conexões entre textos
- Estudos exegéticos
- Personagens, temas e profecias
- Hebraico, grego koiné e aramaico
- Geografia e cronologia bíblicas
- Favoritos e área administrativa

## Princípios editoriais
O aplicativo não deve inventar referências, significados lexicais ou relações entre textos. Toda conexão deve apresentar sua classificação, justificativa e referências bíblicas para conferência.

## Tecnologia
Aplicação web responsiva construída com React, TypeScript e Vite. A integração com banco de dados e autenticação será definida em uma etapa posterior.
